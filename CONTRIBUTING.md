# Contributing to industrialstats

Thank you for considering contributing to industrialstats. The following guidelines help maintain quality and consistency.

## Development Workflow
1. Fork the repository and create a feature branch.
2. Install dependencies with `poetry install`.
3. Run `pre-commit run --all-files` and `pytest` before submitting.
4. Ensure docstrings use NumPy style and include examples.
5. Submit a pull request with a clear description of changes.

## Code Style
- Follow PEP 8 and the project's configured tools (`black`, `isort`, `flake8`).
- Include type hints and informative log messages for all new code.

## Reporting Issues
Please file issues via GitHub with a minimal reproducible example when possible.

## Community
By participating you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
